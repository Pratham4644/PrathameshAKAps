# Prathamesh Shinde Portfolio

Simple Flask portfolio app with content managed from one Python file.

## Run locally

```bash
pip install -r requirements.txt
python app.py
```

Open: `http://127.0.0.1:5000`

## Project structure

- `app.py`: Flask entrypoint and route setup
- `requirements.txt`: Python dependencies
- `portfolio/content.py`: Profile data, projects, skills, links
- `portfolio/templates/index.html`: UI template (HTML/CSS/JS)

## Edit content

Update `portfolio/content.py` to change text, links, projects, skills, and profile details.
